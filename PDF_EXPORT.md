# PDF Экспорт аналитики

Этот документ описывает функционал экспорта аналитики в PDF формат.

## Обзор

Приложение Citrus теперь поддерживает генерацию красивых PDF отчётов с аналитикой ментального здоровья. Пользователи могут экспортировать:

- Общие метрики (серия дней, % хороших дней, среднее настроение, сон)
- График настроения за неделю
- Распределение настроения
- Инсайты и рекомендации
- Статистику активности

## Архитектура

```
analytics_screen.dart
        ↓
pdf_report_service.dart
        ↓
analytics_report.dart (модель данных)
        ↓
Printing.layoutPdf (предпросмотр и печать)
```

## Файлы проекта

### Модели
- `lib/models/analytics_report.dart` - модель данных для отчёта

### Сервисы
- `lib/services/pdf_report_service.dart` - сервис генерации PDF

### Экраны
- `lib/screens/analytics_screen.dart` - экран аналитики с кнопкой экспорта

## Зависимости

Добавлены в `pubspec.yaml`:
- `pdf: ^3.10.7` - библиотека для генерации PDF
- `printing: ^5.11.0` - библиотека для предпросмотра и печати

## Как использовать

1. Откройте экран "Аналитика" в приложении
2. Нажмите кнопку "PDF" в секции "Экспорт"
3. Откроется диалог предпросмотра PDF
4. Вы можете:
   - Сохранить PDF на устройство
   - Распечатать отчёт
   - Отправить по email/messenger и т.д.

## Интеграция с реальными данными

Сейчас используется демо-версия данных (`_createSampleReport`). Для интеграции с реальными данными:

1. Обновите `_createSampleReport()` в `analytics_screen.dart`
2. Получите данные из `DashboardBloc` и репозиториев:

```dart
AnalyticsReport _createRealReport() {
  final dashboardState = context.read<DashboardBloc>().state;
  // ... получите данные из BLoC
  return AnalyticsReport(...);
}
```

3. Замените вызов в `_generatePdfReport()`:
```dart
final report = _createRealReport(); // вместо _createSampleReport()
```

## Настройка стилей

### Цвета
Цвета графиков определены в `_getMoodBarColor()`:
```dart
PdfColor _getMoodBarColor(double value) {
  if (value >= 5) return PdfColors.green;
  if (value >= 4) return PdfColors.lightGreen;
  if (value >= 3) return PdfColors.orange;
  if (value >= 2) return PdfColors.orangeAccent;
  return PdfColors.redAccent;
}
```

### Шрифты
Размеры шрифтов:
- Заголовки секций: 18pt bold
- Заголовок документа: 24pt bold
- Текст метрик: 22pt bold
- Основной текст: 10-11pt
- Подписи: 8-9pt

### Формат страницы
- Формат: A4
- Поля: 32px
- Шапка и подвал на каждой странице

## Troubleshooting

### Ошибка при генерации PDF
**Причина:** Проблема с данными или зависимостями
**Решение:**
1. Проверьте логи: `flutter logs`
2. Убедитесь, что `flutter pub get` выполнен
3. Проверьте данные в `_createSampleReport()`

### PDF не отображается
**Причина:** Проблема с пакетом printing
**Решение:**
1. Перезапустите приложение
2. Проверьте права на хранение (Android/iOS)
3. Обновите пакеты: `flutter pub upgrade`

### Медленная генерация
**Причина:** Большой объём данных
**Решение:**
1. Оптимизируйте данные (меньше записей)
2. Добавьте индикатор загрузки (уже есть)
3. Кэшируйте отчёты

## Пример кода генерации

```dart
// Создать отчёт
final report = AnalyticsReport(
  period: ReportPeriod(
    label: 'Неделя',
    startDate: DateTime(2026, 4, 6),
    endDate: DateTime(2026, 4, 13),
  ),
  metrics: ReportMetrics(
    totalDays: 30,
    goodDaysPercent: 71,
    improvementPercent: 15,
    streakDays: 7,
    averageMood: 4.1,
    averageSleepHours: 7.5,
  ),
  // ... другие данные
);

// Сгенерировать PDF
final pdfService = PdfReportService();
final doc = pdfService.generateReport(report);

// Показать предпросмотр
await Printing.layoutPdf(
  onLayout: (format) async => doc.save(),
  name: 'citrus_analytics.pdf',
);
```
